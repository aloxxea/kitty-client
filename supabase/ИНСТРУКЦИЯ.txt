================================================
ГАЙД: НАСТРОЙКА SUPABASE ДЛЯ KITTY CLIENT
================================================

ШАГ 1. СОЗДАТЬ АККАУНТ И ПРОЕКТ
--------------------------------
1. Открой https://supabase.com и нажми "Start your project" / "Sign up".
2. Зарегистрируйся (можно через GitHub или email).
3. Войди в дашборд https://supabase.com/dashboard
4. Нажми "New project".
   - Organization: создай новую (любое имя, напр. "Kitty")
   - Name: kitty-client
   - Database password: придумай надёжный пароль (запиши!)
   - Region: выбери ближайший (напр. Frankfurt eu-central-1)
   - Нажми "Create new project". Подожди ~1-2 минуты создания.

ШАГ 2. ПОЛУЧИТЬ URL И ANON KEY
--------------------------------
В дашборде проекта слева меню -> Settings -> API
(или Settings -> General снизу, где показан Project URL).

Скопируй эти 2 значения:
  - Project URL   -> это то, что заменить в config.js (SUPABASE_URL)
  - anon public   -> (это ключ, начинается с eyJhbGciOiJIUzI1NiIs...) заменить в config.js (SUPABASE_ANON)

ВНИМАНИЕ: бери именно "anon public", НЕ "service_role".
service_role даёт полный доступ — никогда не используй его на клиенте!

ШАГ 3. СОЗДАТЬ ТАБЛИЦЫ (SQL)
--------------------------------
1. В дашборде проекта слева меню -> SQL Editor -> New query.
2. Открой файл  supabase/schema.sql  (в папке проекта).
3. Скопируй ВЕСЬ его код и вставь в SQL Editor.
4. Нажми "Run" (кнопка запуска). Должно выполниться без ошибок.
5. Это создаст: таблицы profiles, keys, used_keys + функции админки + RLS.

ШАГ 4. ОТКЛЮЧИТЬ ПОДТВЕРЖДЕНИЕ EMAIL (ВАЖНО!)
------------------------------------------------
1. В дашборде проекта слева меню -> Authentication -> Providers -> Email.
2. Найди каталог "Confirm email" / "Подтверждение email".
3. ВЫКЛЮЧИ переключатель (confirm email = off).
4. Сохрани (Save).
Это нужно, чтобы регистрация проходила сразу, без подтверждения почты.

ШАГ 5. ВСТАВИТЬ КЛЮЧИ В КОД
-------------------------------
1. Открой файл  config.js  в папке проекта (обычным блокнотом).
2. Вставь твой Project URL вместо:
     https://YOUR-PROJECT.supabase.co
3. Вставь твой anon key вместо:
     eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...ReplaceWithYourAnonKey
4. Сохрани файл.

ШАГ 6. ПРОВЕРИТЬ ЛОКАЛЬНО
--------------------------------
В браузере открой index.html — если всё ок, регистрация/вход будут
работать с общей базой.

ПРИМЕЧАНИЕ: браузер при открытии через file:// может блокировать
некоторые запросы. Лучше всего тестить уже на хостинге (Netlify),
куда загрузишь папку с добавленными файлами.

ШАГ 7. ЗАГРУЗИТЬ НА ХОСТИНГ
--------------------------------
Перетащи папку проекта на https://app.netlify.com/drop
(обязательно включи новые файлы: config.js, supabase.js, auth.js)
